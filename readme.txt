Manage WooCommerce order tasks, track partial shipments, and create custom order statuses to keep fulfillment moving.

== Description ==

Keep every order moving with Out the Door. Organize order-related tasks, manage partial shipments, and create custom order statuses, all from within WordPress.

Whether you're coordinating fulfillment tasks, shipping an order in multiple batches, or building a workflow that fits your business, Out the Door gives your team a clear view of what needs to happen next.

= Order Task Management =

Turn each WooCommerce order into an actionable workflow by adding tasks directly to it. Every task can include:

* A title and description
* A priority level
* A status, such as In Progress or Completed
* A due date

See outstanding and completed tasks on the order screen, so your team knows what's done and what still needs attention.

For a broader view, use the dashboard to check tasks due today or review all tasks in a visual Kanban board or calendar view. Prioritize work, track progress, and keep important order-related actions from being overlooked.

= Partial Shipments =

Not every order is ready to ship at once. Out the Door lets you mark any quantity of an ordered item as shipped while keeping the remaining quantity open for later fulfillment.

When part of an order ships, the order is marked as partially shipped. The dashboard brings partially shipped orders together in one place, showing:

* Which products have already shipped
* The quantity shipped for each product
* Which products and quantities still need to be sent

Keep track of split shipments, manage backorders, and coordinate staggered fulfillment with a clear view of what's shipped and what's still outstanding.

= Custom Order Statuses =

Build an order workflow that reflects how your store operates. Out the Door lets you create as many custom order statuses as you need, giving your team a clear way to track the stages that matter to your business.

Use custom statuses to make each order's progress easier to understand and keep everyone working from the same information.

= Get Your Orders Out the Door =

Bring order tasks, partial shipment tracking, and custom statuses together in one place. Spend less time piecing together order information and more time getting orders ready, shipped, and out the door.

== Installation ==

1. Install and activate WooCommerce.
2. In your WordPress dashboard, go to Plugins > Add New Plugin > Upload Plugin and upload the Out the Door plugin ZIP file.
3. Install and activate Out the Door.

== Frequently Asked Questions ==

= Does Out the Door require WooCommerce? =

Yes. Out the Door works with WooCommerce orders and requires WooCommerce to be installed and active.

= Can I add multiple tasks to an order? =

Yes. Add order-related tasks with their own titles, descriptions, priorities, statuses, and due dates. Review outstanding and completed tasks on the order screen.

= Can I see tasks across different orders? =

Yes. Use the dashboard to check tasks due today, or review all tasks in a Kanban board or calendar view.

= Can I track an order that ships in multiple batches? =

Yes. Mark the shipped quantity of each ordered item and leave the remaining quantity open for later fulfillment. The dashboard shows partially shipped orders with shipped and outstanding quantities.

= Can I create my own order statuses? =

Yes. Create as many custom order statuses as you need to reflect your store's workflow.
